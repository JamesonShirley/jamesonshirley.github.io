Contested Space

A 2–4 player cooperative roguelike deckbuilding game set in a contested galaxy, developed solo in Godot 4 under Null & Void Games. Players draft cards in real time from a personal market that evolves mid-combat, deploy stations for tactical bonuses, and battle across 20 incursion levels with six factions, branching star maps, and run-defining relics — all rendered in handcrafted pixel art with full Steam Deck support. Currently in playtesting with Steam wishlisting available.

Court Case Management System

A court case management system built with Python Django and JavaScript Next.js. It allows courts to schedule hearings and keep track of them in a calendar. It also allows for the creation of cases and the tracking of case information, as well as court orders and other documents. It keeps track of the parties involved in the case and the attorneys representing them.

Note and Task Tracker

A note and task tracker built in Python Django with vanilla JavaScript. It allows users to take notes and create tasks, connecting the two and displaying a calendar of tasks.

Scheduling Application

This application was built in Java using FXML. It manages customers and appointments for a fictional business. It shows a calendar of all current appointments, and allows for the creation of new appointments and customers. It also has a report that shows the number of appointments by type and month.
